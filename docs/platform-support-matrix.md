# Platform Support Matrix

| Platform | Build | Headless | Interactive client | Package | v0.1 status |
| --- | --- | --- | --- | --- | --- |
| Windows x64 | Required | Required | Required | `win-x64` | Supported target |
| Windows Arm64 | Not validated | Not validated | Not validated | None | Deferred |
| Linux x64 | Not validated | Plausible, untested | Not validated | None | Deferred |
| Steam Deck | Not validated | Not validated | Not validated | None | Deferred |
| macOS Intel/Arm64 | Not validated | Not validated | Not validated | None | Deferred |
| Xbox | Unsupported toolchain | Not applicable | Not validated | None | Deferred |
| Android/iOS | Unsupported project shape | Not applicable | Not validated | None | Deferred |
| Web | Unsupported runtime | Not applicable | Not validated | None | Deferred |

The use of DesktopGL does not itself constitute support for a platform. A
platform becomes supported only after its prerequisites, restore, build, tests,
interactive runtime, packaging, and operating documentation are verified.
